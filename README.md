# HAPT Vocabulary
High-Risk AI and Data Protection Taxonomy

A SKOS vocabulary for high-risk AI systems and data protection use cases. Accessible at: https://tyttikatariina.github.io/HAPT/. This taxonomy reused the Data Privacy Vocabulary, AIRO and VAIR.
